# 税务师《涉税服务相关法律》刷题页

一个零依赖的单文件静态网页，题库内嵌在 `index.html` 中，无需构建、无需后端、无需联网加载第三方资源。

## 用法

直接用浏览器打开仓库发布的 Pages 地址，或把 `index.html` 下载到本地双击打开即可。

在线地址：<https://jkray511.github.io/tax-quiz/>

## 功能

- 单选题 / 多选题 / 判断题分类练习
- 即时判分与答案解析
- 答题进度与对错记录保存在浏览器 `localStorage`（键名 `quiz_answers`）

## 关于进度存储

进度按**域名 + 浏览器**隔离存储，因此：

- 换浏览器、换设备、使用无痕模式，进度不会同步
- 清理浏览器数据会重置全部作答记录
- 本地文件打开与线上地址是两套独立记录

## 技术说明

| 项目 | 说明 |
| --- | --- |
| 构建 | 无，纯静态单文件 |
| 外部依赖 | 无 CDN、无字体、无框架 |
| 部署 | GitHub Pages（branch `main`，根目录） |
